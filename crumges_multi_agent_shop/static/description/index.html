Multi Agent Shop

“Potencie a sus agentes: Permítales comprar por sus clientes directamente desde la web.” 🚀

✅ Community ✅ Enterprise

¿Por qué usar este módulo? 🤔

Facilite la vida de sus vendedores de campo y agentes B2B. En lugar de complicados procesos backend, deles una herramienta simple en el Ecommerce para seleccionar un cliente y cargar un pedido en su nombre, asegurando que las comisiones y la facturación sean correctas. ✨

Funcionalidades 🌟

🤝
Compra Asistida

El agente opera la web, pero el pedido se registra para el cliente final.

👤
Selección de Cliente

Selector dedicado para cambiar de cliente en un clic.

📄
Trazabilidad

El pedido guarda quién fue el cliente y quién el agente.

🛑
Seguridad

Alertas inteligentes al cambiar de cliente para proteger el carrito.

Configuración ⚙️

1
Activar Agente
En el contacto (Partner), asegúrese de que tenga usuario de Portal.
2
Asignar Clientes
Relacione al Agente con sus Clientes (ej: campo "Vendedor").

Modo de Uso 🛠️

Flujo típico de un agente:

👉
Entrar el sitio web y click en el menú Agent Shop.
👉
Seleccionar al Cliente del desplegable.
👉
Agregar productos al carrito y finalizar compra (Checkout).
✅
¡Listo! El pedido se crea a nombre del cliente seleccionado.

Caso de Uso 💡

📱 Venta de Campo

Un vendedor visita una tienda de barrio "Kiosco Pepe".
Problema: Tomar nota en papel es lento. El backend de Odoo es muy complejo para usar en una tablet rápida.
Solución: El vendedor abre la web en su celular, selecciona "Kiosco Pepe", escanea o busca los productos que faltan y confirma el pedido ahí mismo. "Kiosco Pepe" recibe la factura y el vendedor su comisión. 👏

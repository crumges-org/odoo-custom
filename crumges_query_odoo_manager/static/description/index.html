¿Qué hace este módulo?

Control total sobre tus datos en tiempo real

Normalmente, para extraer un listado técnico o realizar un cambio masivo en la base de datos de Odoo necesitas conectarte vía pgAdmin o psql, lo cual es inaccesible para los usuarios regulares del sistema.

Con el Gestor SQL, integras una consola directamente en la interfaz web de Odoo. Los administradores pueden redactar consultas (SELECT, UPDATE, INSERT, DELETE) y visualizarlas, mientras que pueden dar acceso a personal menos técnico para ejecutar aquellas consultas seguras y descargar los reportes.

¿Cuándo necesitás este módulo?

Si alguno de estos casos te resulta familiar, esta herramienta es para vos.

01
Reportes que Odoo no trae por defecto

Imaginate que la gerencia pide un listado muy específico cruzando facturas, ventas y productos que no existe en ningún menú. En vez de desarrollar un módulo entero, escribís la consulta SQL en segundos y bajás el Excel.

02
Datos basura o de prueba que molestan

O tenés registros generados durante la implementación que ahora estorban en las vistas oficiales, pero desde la interfaz Odoo no te deja borrarlos por reglas de archivo. Un DELETE cuidadoso es la solución directa.

03
Actualización masiva de precios o categorías

Quizás tenés que cambiar la categoría interna de 5.000 productos. Hacerlo a mano es inviable o lento. Con un UPDATE SQL cambiás todo el catálogo al instante.

04
Auditoría de integridad referencial

Y el peor escenario: un error de importación generó facturas huérfanas o transacciones cortadas. Con esta consola ubicás la data corrupta directamente en las tablas y la neutralizás sin salir de la vista web.

Lo más destacado

Funcionalidades principales

⚡ Ejecución Universal

Permite ejecutar DML completo: SELECT para reportes, UPDATE, DELETE e INSERT para arreglos masivos o inserciones directas.

🛡️ Seguridad por Roles

Distingue y aísla entre un Administrador SQL (control total del código) y un Ejecutor SQL (solo visualización de grids de datos).

📊 Exportación a Excel

Exporta tabulados los datos de respuesta a un archivo Excel nativo con celdas cebra y encabezados limpios.

🧠 Tipificación IA

Basándose en la semántica del query redactado, el modelo detecta e identifica el tipo de la consulta de forma automática.

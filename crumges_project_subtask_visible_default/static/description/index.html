Project Subtask Visible Default

“Revele sus subtareas: Haga que el trabajo granular sea visible por defecto.” 🚀

✅ Community ✅ Enterprise

¿Por qué usar este módulo? 🤔

Odoo oculta las subtareas de las vistas principales para "limpiar" la interfaz, pero esto a menudo esconde trabajo importante. Este módulo invierte ese comportamiento: si crea una subtarea, es porque quiere verla y trabajar en ella. ✨

Funcionalidades 🌟

👁️
Visibilidad Inmediata

Las subtareas aparecen en el Kanban y Lista al momento de crearse.

⚙️
Cero Configuración

Instalar y olvidar. Funciona automáticamente en segundo plano.

🔄
Retrocompatibilidad

Soporta múltiples versiones y configuraciones de campos de visibilidad.

Modo de Uso 🛠️

El funcionamiento es transparente:

👉
Cree una Subtarea dentro de una tarea existente.
👉
Vaya a la vista Kanban del proyecto.
✅
¡Listo! Su subtarea ya estará visible como una tarjeta independiente.

Caso de Uso 💡

💻 Desarrollo de Software

Un equipo gestiona un backlog.
Problema: Las "Historias de Usuario" (Tareas Padres) se descomponen en "Tasks Técnicas" (Subtareas). Los desarrolladores necesitan ver esas subtareas en el tablero Kanban para moverlas de estado, pero Odoo las oculta por defecto.
Solución: Con este módulo, al crear la subtarea técnica, esta aparece inmediatamente en el tablero junto a las demás, lista para ser gestionada. 👏

Este módulo mejora la experiencia de usuario en la gestión de hojas de tiempo
relacionadas con subtareas de proyectos en Odoo.

**Características:**

* Interfaz mejorada para el registro de tiempo en subtareas
* Visualización optimizada de datos de tiempo
* Mejores controles de validación
* Experiencia de usuario más intuitiva en la gestión de tiempos

**Mejoras incluidas:**

* Campos de tiempo más accesibles en la vista de subtareas
* Cálculo automático de duraciones
* Validaciones mejoradas de entrada de datos
* Interfaz responsiva para dispositivos móviles

Instalación
===========

Para instalar este módulo, necesitas:

1. Descargar el módulo en tu directorio de addons
2. Actualizar la lista de módulos
3. Instalar el módulo "Project Subtask Timesheet UX"

Uso
===

Una vez instalado, el módulo proporciona:

* Vistas mejoradas de hojas de tiempo en subtareas
* Funcionalidades de validación automática
* Mejor visualización de datos temporales

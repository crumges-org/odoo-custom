Características
===============

*   **🌍 Acceso Democrático**: Cualquier seguidor de un proyecto puede registrar horas. ¡Sin configuraciones complejas!
*   **📉 Cero Fricción**: Interfaz de portal simplificada para cargas rápidas.
*   **🔗 Auto-Link**: Vinculación inteligente con el empleado correspondiente si existe.

Configuración
=============

Simplemente añada al usuario como **Seguidor** en el proyecto. El módulo hace el resto.

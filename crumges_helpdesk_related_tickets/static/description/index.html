Helpdesk Ticket Hierarchy

“Organice el caos: Agrupe múltiples incidencias bajo un caso maestro.” 🧩

✅ Odoo Enterprise Required

¿Por qué usar este módulo? 🤔

Cuando un servicio crítico falla, el Helpdesk se inunda de reportes duplicados o relacionados. Odoo Helpdesk estándar no vincula tickets entre sí. Este módulo añade la pieza faltante: Jerarquía Padre/Hijo. Le permite agrupar 50 tickets de "Internet lento" bajo un solo Ticket Padre "Caída de Fibra Óptica", gestionándolos en bloque. 📉

Funcionalidades 🌟

👨‍👦
Relación Padre/Hijo

Vincule tickets ilimitados a un caso principal para mantener el orden.

🔄
Herencia de Cliente

Al asignar un padre, el ticket hijo hereda automáticamente el cliente del caso principal.

🌍
Visibilidad Portal

Sus clientes pueden ver los tickets relacionados desde su portal web.

Modo de Uso 🛠️

Gestión de crisis simplificada:

👉
Detecta un problema mayor (ej: "Servidor caído"). Crea un Ticket Padre para ello.
👉
A medida que llegan reportes de usuarios, en el campo "Parent Ticket" selecciona su ticket maestro.
✅
Desde el ticket padre, puede ver y acceder a todos los tickets hijos relacionados en una pestaña dedicada, cerrando el caso globalmente cuando se resuelva.

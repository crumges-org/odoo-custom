Product Attribute Price Percentage

Este módulo permite definir un porcentaje de incremento sobre el precio de un producto en la tabla product.template.attribute.value.

Características

  • Define un porcentaje de incremento para valores de atributos.
  • El cálculo del precio adicional es automático.
  • Compatible con la gestión de variantes de productos.

Uso

  1. Accede a la configuración de atributos de producto.
  2. Define un porcentaje de incremento.
  3. El precio adicional se actualizará en base al porcentaje.

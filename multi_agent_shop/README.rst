Multi Agent Shop
================

Este módulo es una **adaptación mejorada** del módulo "Shopping Through Agent" de 
`Cybrosys Technologies Pvt. Ltd. <https://www.cybrosys.com/>`_, con mejoras significativas 
en seguridad, permisos de usuario y soporte completo para usuarios de portal.

Multi Agent Shop revoluciona la experiencia de compra en Odoo al permitir que agentes
(usuarios internos y de portal) realicen pedidos de venta directamente en el sitio web,
actuando en nombre de sus clientes asignados.

**Características principales:**

* ✅ Compras por agentes en nombre de clientes
* ✅ Soporte completo para usuarios de portal como agentes
* ✅ Soporte para usuarios internos con permisos completos
* ✅ Gestión de clientes asignados a cada agente
* ✅ Interfaz intuitiva con menú "Multi Agent Shop"
* ✅ Trazabilidad completa de agentes en pedidos
* ✅ Manejo automático de direcciones de facturación y envío
* ✅ Reportes mejorados con información de agentes
* ✅ Validaciones de seguridad y permisos robustas
* ✅ Compatible con módulo complementario `shopping_through_agent_ux`

Configuración
=============

Marcando Contactos como Agentes
-------------------------------

1. Abrir un contacto en Odoo
2. Ir a la pestaña "Sales/Purchases"
3. En la sección "Información de Agente":
   - Marcar la opción "Es Agente"
   - Opcionalmente asignar un agente superior
4. Guardar

Asignando Clientes a Agentes
-----------------------------

1. Abrir un cliente (contacto)
2. Ir a la pestaña "Sales/Purchases"
3. En el campo "Agente", seleccionar el agente responsable
4. Guardar

El cliente ahora aparecerá en la lista de clientes disponibles para ese agente.

Uso
===

Para Agentes (Usuarios Internos o de Portal)
---------------------------------------------

1. Iniciar sesión como agente (usuario interno o de portal)
2. Acceder al menú "Multi Agent Shop" (en el menú de navegación)
3. Seleccionar el cliente para el cual desea realizar la compra
4. Hacer clic en "Shop Now"
5. Navegar por los productos normalmente
6. Agregar productos al carrito
7. Proceder con el checkout
8. El pedido se crea automáticamente con:
   - Cliente: El cliente seleccionado
   - Agente: El usuario conectado
   - Dirección de facturación: Del cliente
   - Dirección de envío: Del cliente

Para Administradores
--------------------

**Ver pedidos con información de agente:**

1. Ir a Ventas → Órdenes
2. Abrir una orden creada por un agente
3. Ver el campo "Agente" con la información del usuario que realizó la compra

**Generar reportes:**

1. Ir a Ventas → Reportes
2. Los reportes mostrarán información segmentada por agente
3. Analizar el desempeño de ventas por agente

Campos Añadidos
===============

Modelo: res.partner
-------------------

* **is_agent** (Boolean): Indica si el contacto es un agente
* **agent_id** (Many2One): Agente asignado al cliente
* **agent_ids** (Many2Many): Múltiples agentes asignados al cliente

Modelo: sale.order
-------------------

* **agent_id** (Many2One): Agente que realizó la compra

Modelo: account.move
--------------------

* **agent_id** (Many2One): Agente del pedido de venta asociado

Flujo de Seguridad
==================

El módulo implementa múltiples capas de seguridad:

1. **Validación de Agente**: Solo usuarios marcados como agentes pueden acceder
2. **Validación de Cliente**: El cliente debe estar asignado al agente
3. **Validación de Permisos**: Uso estratégico de permisos para operaciones específicas
4. **Validación de Usuario de Portal**: Soporte seguro para usuarios de portal sin exposición de datos
5. **Registro de Auditoría**: Cada compra queda registrada con el agente responsable

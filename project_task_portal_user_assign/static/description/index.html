Assign Portal Users to Project Tasks

This module removes the default restriction in Odoo that prevents selecting portal users as assignees in project tasks. It allows you to assign portal users as responsible for tasks without giving them access to the backend.

It's ideal for scenarios where you want to track responsibilities involving external collaborators or clients, but you do not want them to log in to the backend.

  • Compatible with Odoo 17
  • No dependency on portal_backend
  • Lightweight, safe and easy to uninstall

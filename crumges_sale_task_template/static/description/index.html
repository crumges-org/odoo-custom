Sale Task Template

“Estandarice sus servicios: Venda productos y genere estructuras de trabajo completas al instante.” 🚀

✅ Community ✅ Enterprise

¿Por qué usar este módulo? 🤔

Odoo crea tareas al vender servicios, pero vienen vacías. Si sus servicios siempre requieren los mismos pasos (ej: "Diseño", "Desarrollo", "QA"), pierde tiempo recreándolos manualmente. Este módulo le permite definir una Tarea Maestra y clonarla automáticamente con cada venta. ✨

Funcionalidades 🌟

📋
Plantillas Maestras

Diseñe la tarea perfecta una vez y úsela para siempre.

⚡
Clonado Automático

Al confirmar la venta, la tarea se crea con todo el contenido predefinido.

🧩
Subtareas Incluidas

Copia la estructura completa de subtareas y sus horas asignadas.

🏷️
Detalle Rico

Mantiene etiquetas, descripciones, checklists y colores.

Configuración ⚙️

1
Crear Plantilla
Cree una Tarea en Odoo con todas las subtareas y detalles que desee usar como modelo.
2
Asignar al Producto
Vaya a su Producto de Servicio, pestaña Ventas, y seleccione la tarea en el campo "Task Template".

Modo de Uso 🛠️

Flujo de trabajo optimizado:

👉
Cree un Presupuesto con el servicio configurado.
👉
Confirme la venta.
✅
Odoo generará el proyecto y la tarea, pero esta vez la tarea tendrá todas las subtareas y datos de su plantilla original instantáneamente.

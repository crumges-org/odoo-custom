Características
===============

*   **🧠 Automatización Inteligente de Estados**:
    *   🔵 **En Progreso**: Si alguna subtarea está en marcha.
    *   🟠 **Cambios Solicitados**: Si las horas consumidas superan lo asignado.
    *   🟢 **Hecho**: Si se completan las horas exactas y no quedan pendientes.
    *   🟣 **Aprobado**: Si se completa consumiendo menos horas de las asignadas.

*   **⏱️ Partes de Horas Automáticos**:
    Al marcar una tarea como "Hecho", se genera el parte de horas automáticamente (si tenía horas asignadas).

*   **🛡️ Asistentes de Seguridad**:
    *   **Cancelar**: Previene accidentes validando horas registradas.
    *   **Finalización Forzada**: Permite cerrar tareas complejas con un solo clic.

Configuración
=============

1.  Vaya a cualquier **Tarea Raíz**.
2.  Active el interruptor **"Registrar Horas Automáticamente"**.
3.  ¡Listo! La lógica se aplicará a todas sus subtareas.

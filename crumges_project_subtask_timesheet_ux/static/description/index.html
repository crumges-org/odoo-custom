¿Por qué usar este módulo? 🤔

La gestión manual de estados en proyectos complejos es propensa a errores. ¿Olvidó actualizar la tarea padre cuando completó las subtareas? ¿Cerró una tarea sin registrar las horas restantes? Este módulo automatiza el flujo: calcula estados, valida acciones y autocompleta timesheets para mantener sus datos impecables. 🧠

Funcionalidades 🌟

🤖
Estados Automáticos

La tarea padre actualiza su estado según las horas consumidas vs asignadas de sus hijos.

⏱️
Auto-Timesheet

Al finalizar una tarea, puede completar automáticamente las horas asignadas restantes.

🛡️
Validación Inteligente

Impide cerrar o cancelar tareas si hay inconsistencias (hijos abiertos, horas sin borrar).

🌊
Acciones en Cascada

Al cambiar el estado (Cancelar/Reabrir), la acción se propaga automáticamente a las subtareas.

Configuración ⚙️

1
Activar Automatización (Opcional)
En la tarea raíz (Padre), active el check "Registrar Horas Automáticamente" si desea que el sistema rellene los huecos de tiempo al completar tareas.

Modo de Uso 🛠️

El sistema trabaja por usted:

👉
Trabaje en sus Subtareas registrando horas normalmente.
👉
La Tarea Padre cambiará sola de estado:
  • En Progreso: Si hay hijos abiertos.
  • Aprobado: Si se consumió menos de lo asignado.
  • Cambios Solicitados: Si se excedieron las horas.
  • Hecho: Si las horas coinciden exactamente.
✅
Use la Barra de Estado estándar. El sistema se encargará de propagar los cambios (como Cancelar o Reabrir) a todas las subtareas automáticamente.

Project Task Autoname

“Orden y Estándar: Nombres de tareas automáticos, limpios y fáciles de buscar.” 🏷️

✅ Community ✅ Enterprise

¿Por qué usar este módulo? 🤔

En operaciones con alto volumen de tareas, los nombres libres ("Revisar", "Ver fallo") generan caos. Este módulo impone una estructura profesional, asegurando que cada tarea tenga un identificador único (ID), un propósito claro y una descripción concisa. Esencial para talleres y servicios técnicos. ✨

Funcionalidades 🌟

🏷️
Formato Estándar

[ID] - Propósito - Info.
Uniformidad total en sus listas de tareas.

📋
Propósitos

Configure categorías predefinidas (Reparación, Instalación) para agilizar la carga.

🔒
Integridad

El nombre se "congela" tras generarse para evitar ediciones manuales erróneas.

Configuración ⚙️

1
Definir Propósitos
Vaya a Proyecto > Configuración > Task Purposes y cree sus opciones (ej: Diagnóstico, Presupuesto, Entrega).

Modo de Uso 🛠️

Al crear una tarea:

👉
Seleccione el modo Auto-generated Name.
👉
Elija el Propósito y añada Información Adicional (ej: Matrícula, Nº Serie).
✅
Al guardar, el sistema asignará el ID y formará el nombre final automáticamente.

Caso de Uso 💡

🏭 Taller Mecánico

Llegan 5 coches para revisión.
Problema: Si se pone solo "Revisión" en el nombre, nadie sabe cuál es cuál.
Solución: El recepcionista pone Info: "Toyota Yaris ABC-123". El sistema crea: [1054] - Mantenimiento - Toyota Yaris ABC-123. Único, claro y profesional. 🏎️

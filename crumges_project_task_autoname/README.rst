Funcionalidades 🌟
==================

*   🏷️ **Formato Estándar:** Genera nombres tipo `[ID: 1052] - Instalación - Cliente X`.
*   📋 **Catálogo de Propósitos:** Defina propósitos estándar (Reparación, Mantenimiento, Instalación) para categorizar el trabajo.
*   🔒 **Integridad de Datos:** El nombre se congela tras la creación automática, impidiendo modificaciones manuales accidentales que rompan la trazabilidad.
*   🆔 **ID Visible:** El ID de la tarea pasa a formar parte del nombre, facilitando la búsqueda rápida.

Caso de Uso 💡
==============

**Taller de Reparaciones**

Un taller recibe decenas de equipos al día.

*   **Problema:** Los técnicos crean tareas con nombres como "Reparar PC", haciendo imposible saber de qué cliente es o qué PC es sin abrir la tarea.
*   **Solución:** Con Autoname, el recepcionista elige Propósito: "Diagnóstico" e Info: "Laptop Dell XYZ". El sistema genera: **[2045] - Diagnóstico - Laptop Dell XYZ**.  Cualquiera en el taller puede referenciar la "2045" inequívocamente.

Configuración ⚙️
================

1.  Vaya a **Proyecto > Configuración > Task Purposes**.
2.  Cree sus propósitos comunes (ej: Mantenimiento, Garantía, Urgencia).

Modo de Uso 🛠️
==============

1.  Cree una nueva tarea.
2.  En el campo "Task Naming", seleccione **"Auto-generated Name"**.
3.  Elija el **Propósito** y escriba la **Información Adicional**.
4.  Al guardar, el nombre se sobrescribirá automáticamente con el formato estándar.

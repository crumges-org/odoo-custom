**Extienda su fuerza laboral: Integre contratistas y externos a su flujo de trabajo asignándoles tareas directamente.** 🚀

Este módulo permite asignar tareas de proyectos a usuarios de tipo Portal, siempre y cuando estos usuarios tengan un registro de Empleado asociado.

**Compatibilidad**

*   ✅ Odoo Community
*   ✅ Odoo Enterprise

Funcionalidades 🌟
==================

*   🎯 **Asignación Directa:** Permite seleccionar usuarios Portal en el campo "Asignado a".
*   🛡️ **Seguridad Intacta:** Los externos mantienen su perfil restringido de "Portal".
*   👥 **Conexión RRHH:** Vincula el trabajo externo con fichas de Empleados reales.

Caso de Uso 💡
==============

**👷 Gestión de Electricistas Externos**

Una constructora subcontrata electricistas.

*   **Problema:** Quieren asignarles tareas para que reporten horas, pero no quieren pagar licencias de usuario interno ni darles acceso a toda la empresa.
*   **Solución:** Crean usuarios portal y fichas de empleado. Con este módulo, el Project Manager les asigna tareas directamente. El electricista entra a su portal, ve su tarea y trabaja. 👏

Configuración ⚙️
================

1.  **Crear Usuario Portal:** Vaya a *Ajustes > Usuarios* y cree el usuario.
2.  **Crear Empleado:** Vaya a *Empleados* y cree una ficha.
3.  **Vincular:** En el Empleado, pestaña *Configuración RRHH*, asigne el **Usuario Portal** en el campo "Usuario Relacionado". 🔗

Modo de Uso 🛠️
==============

1.  Navegue a cualquier **Proyecto** o **Tarea**.
2.  Haga clic en el campo **Asignado a**.
3.  ¡Listo! El usuario Portal aparecerá disponible para ser seleccionado. ✅

Portal User Assignment

“Extienda su fuerza laboral: Integre contratistas y externos a su flujo de trabajo asignándoles tareas directamente.” 🚀

✅ Community ✅ Enterprise

¿Por qué usar este módulo? 🤔

Por defecto, Odoo solo permite asignar usuarios internos. Este módulo elimina esa barrera, permitiendo asignar tareas a Usuarios Portal que tengan un Empleado asociado. Ideal para contratistas y freelancers. ✨

Funcionalidades 🌟

🎯
Asignación Directa

Permite seleccionar usuarios Portal en el campo "Asignado a".

🛡️
Seguridad Intacta

Los externos mantienen su perfil restringido de "Portal".

👥
Conexión RRHH

Vincula el trabajo externo con fichas de Empleados reales.

Configuración ⚙️

1
Crear Usuario Portal
Vaya a Ajustes > Usuarios y cree el usuario para su contratista.
2
Crear Empleado
Vaya a Empleados y cree una ficha para esa persona.
3
Vincular
En el Empleado, pestaña Configuración RRHH, asigne el Usuario Portal en el campo "Usuario Relacionado". 🔗

Modo de Uso 🛠️

Una vez configurado, es así de simple:

👉
Navegue a cualquier Proyecto o Tarea.
👉
Haga clic en el campo Asignado a.
✅
¡Listo! El usuario Portal aparecerá disponible para ser seleccionado.

Caso de Uso 💡

👷 Gestión de Electricistas Externos

Una constructora subcontrata electricistas.
Problema: Quieren asignarles tareas para que reporten horas, pero no quieren pagar licencias de usuario interno ni darles acceso a toda la empresa.
Solución: Crean usuarios portal y fichas de empleado. Con este módulo, el Project Manager les asigna tareas directamente. El electricista entra a su portal, ve su tarea y trabaja. 👏

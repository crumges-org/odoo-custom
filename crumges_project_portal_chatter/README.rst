**¡Rompe las barreras de comunicación! Colaboración total para usuarios externos.** 🚀

Permite que tus usuarios de portal (vinculados a empleados) visualicen todo el historial del chatter, notas internas y trazabilidad en sus proyectos para una colaboración sin límites.

Funcionalidades 🌟
==================

*   📢 **Visibilidad Total:** Acceso a notas internas, adjuntos y discusiones previas en el chatter que normalmente están ocultas al portal.
*   📊 **Trazabilidad (Tracking):** Visualización de cambios de etapa, asignaciones y modificaciones de campos críticos.

Caso de Uso 💡
==============

**Colaboradores Externos Avanzados**

Un Project Manager externo o un auditor necesita entender el contexto completo de un proyecto.

*   **Problema:** Desde el portal estándar, solo ve mensajes directos ("@usuario"), perdiéndose el contexto de notas internas técnicas o la historia de cambios de estado.
*   **Solución:** Al vincular a este usuario como "Empleado" (aunque sea externo), el módulo habilita la vista completa del chatter. Ahora puede ver que una tarea se bloqueó y leer la nota interna del desarrollador explicando la causa.

Configuración ⚙️
================

1.  Instale el módulo.
2.  Vaya a la aplicación de **Empleados**.
3.  Asegúrese de que el usuario de portal objetivo tenga un registro de empleado creado y vinculado a su usuario (`user_id`).
4.  ¡Listo! La visibilidad se activa automáticamente para esos usuarios.

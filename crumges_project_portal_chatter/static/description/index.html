✅ Community ✅ Enterprise

¿Por qué usar este módulo? 🤔

Por defecto, los usuarios de portal solo ven mensajes enviados explícitamente a ellos. Esto limita la colaboración en proyectos complejos. Este módulo permite que los usuarios de portal (que sean empleados o colaboradores de confianza) vean todas las notas internas y cambios de estado (tracking), tal como lo haría un usuario interno. 👁️

Funcionalidades 🌟

📢
Visibilidad Total

Acceso a notas internas, adjuntos y discusiones previas en el chatter.

📊
Trazabilidad (Tracking)

Visualización de cambios de etapa, asignaciones y modificaciones de campos.

Configuración ⚙️

1
Vincular Empleado
Para activar la visibilidad extendida, asegúrese de que el Usuario de Portal tenga un registro de Empleado asociado en el módulo de RRHH.
2
¡Listo!
Al ingresar al portal y ver un proyecto/tarea, verá el historial completo.

Caso de Uso 💡

🤝 Colaboradores Externos Avanzados

Un Project Manager externo necesita auditar el progreso de un proyecto.
Problema: Desde el portal solo ve mensajes directos, perdiéndose las notas técnicas internas o cambios de estado clave.
Solución: Al vincularlo como "Empleado", el sistema le confía el historial completo. Ahora puede ver que la tarea pasó de "En Progreso" a "Bloqueado" y leer la nota interna explicando el motivo técnico. 👏

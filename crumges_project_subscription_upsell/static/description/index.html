Project Subscription Upsell

“Genere ingresos extra: Facilite ventas adicionales en suscripciones directamente desde las tareas.” 💰

✅ Community ✅ Enterprise

¿Por qué usar este módulo? 🤔

Capture cada oportunidad de venta. Permita que sus técnicos o gestores de proyecto agreguen servicios adicionales (upsell) a una suscripción existente sin tener que navegar al backend de Ventas. Todo integrado, simple y seguro. ✨

Detalle de Funcionalidades 📋

🚀
Gestión de Upsell
  • Creación Directa: Sin salir de la tarea.
  • Cálculo Nativo: Usa lógica Odoo (prorrateos).
  • Vinculación: Task -> Line -> Subscription.
  • Sync: Nombre tarea = Descripción venta.
🛡️
Integridad Workflow
  • Exclusividad Mutua: Bloqueo Upsell vs Subtareas.
  • Candado Bidireccional: No Upsell si hay hijos, y viceversa.
  • Interfaz Dinámica: Se ocultan pestañas no válidas.
🔐
Seguridad
  • Acceso Democratizado: Para usuarios 'Proyecto'.
  • Escalado Seguro: Uso controlado de sudo.
  • Visibilidad Selectiva: Acceso solo lectura a suscripciones.
✨
Experiencia (UX)
  • Siempre Borrador: Evita confirmación accidental.
  • Recarga Suave: Mantiene el foco en la tarea.
  • Reset: Botón de pánico para corregir errores.

Configuración ⚙️

1
Preparar Productos
Vaya a sus productos de servicio. En la pestaña Ventas, active "Upsell from Task".
2
Permisos
El usuario debe tener acceso a Ventas y Proyectos.

Modo de Uso 🛠️

Flujo optimizado:

👉
En la Tarea, active el switch Enable Upsell.
👉
Seleccione la Suscripción (filtrada por cliente) y el Producto.
👉
Marque la tarea como Hecho. Aparecerá el botón Create Upsell.
✅
Haga clic para generar la venta. Si se equivoca, use Reset (solo si no se ha confirmado la venta).

Caso de Uso 💡

🔧 Mantenimiento Extra

Un técnico visita "Empresa X" para un mantenimiento rutinario.
Problema: El cliente pide instalar un nuevo router, servicio no incluido en la cuota.
Solución: El técnico crea la tarea "Instalación Router", selecciona la suscripción de "Empresa X" y el producto "Instalación Extra". Al terminar, le da a "Crear Upsell". La factura se genera automáticamente. 👏

**Genere ingresos extra: Facilite ventas adicionales en suscripciones directamente desde las tareas.** 💰

Este módulo conecta el mundo operativo de Proyectos con el comercial de Suscripciones, permitiendo crear upsells sin salir de la tarea.

Detalle de funcionalidades 📋
===========================

1. Gestión de Ventas Adicionales (Upsell)
-----------------------------------------

*   **Creación Directa:** Genere cotizaciones desde la tarea sin salir del proyecto.
*   **Cálculo Nativo:** Utiliza la lógica nativa de Odoo para prorrateos y precios de suscripción.
*   **Vinculación Automática:** Task -> Sale Line -> Subscription. Todo conectado.
*   **Sincronización Inteligente:** El nombre de la tarea se refleja en la descripción de la línea de venta.

2. Integridad del Flujo de Trabajo (Workflow Safety)
----------------------------------------------------

*   **Exclusividad Mutua Upsell/Subtareas:**
    *   Si hay subtareas, no puede activar Upsell.
    *   Si hay Upsell activo, no puede crear subtareas.
*   **Interfaz Dinámica:** Se ocultan pestañas y botones no permitidos para evitar confusiones.

3. Seguridad y Accesibilidad 🔐
-------------------------------

*   **Acceso Democratizado:** Reglas especiales permiten a usuarios de Proyecto (no ventas) operar el upsell.
*   **Escalado Seguro:** El proceso de creación usa privilegios elevados controlados (sudo) para saltar restricciones sin comprometer la seguridad.
*   **Visibilidad Selectiva:** Los usuarios de proyecto pueden leer las suscripciones necesarias para el upsell, pero no todo el módulo de ventas.

4. Experiencia de Usuario (UX) ✨
---------------------------------

*   **Siempre Borrador:** Garantizamos que el upsell nazca en estado "Borrador" (Draft), evitando confirmaciones accidentales.
*   **Sin Redirecciones:** La vista se recarga suavemente, manteniendo al usuario en su tarea.
*   **Reset de Emergencia:** Botón para eliminar/corregir el upsell si se comete un error (pre-confirmación).

Caso de Uso 💡
==============

**Mantenimiento Extra Facturable**

Un técnico realiza una visita de mantenimiento (parte de la suscripción base) pero detecta que hace falta un repuesto o servicio adicional no incluido.

*   **Problema:** El técnico usualmente no tiene acceso a Ventas o debe avisar a un comercial, perdiendo tiempo y riesgo de olvido.
*   **Solución:** Desde su tarea en el móvil, el técnico selecciona "Material Extra", elige la suscripción del cliente y le da a "Crear Upsell". Listo. El comercial recibe la cotización lista para aprobar.

Configuración ⚙️
================

1.  Vaya al formulario del Producto (tipo Servicio).
2.  En la pestaña **Ventas**, busque el grupo **Upsell Settings**.
3.  Active la opción **"Upsell from Task"**.

Modo de Uso 🛠️
==============

1.  En una Tarea de Proyecto, active el interruptor **"Enable Upsell"**.
2.  Seleccione la **Suscripción** y el **Producto**.
3.  Una vez completado el trabajo, marque la tarea como **Hecho**.
4.  Aparecerá el botón **"Create Upsell"**. Haga clic para generar la cotización.
5.  Si necesita corregir (y el pedido no está confirmado), use **"Reset / Correct Upsell"**.

CRM: Forzar Leads desde Bot

Este módulo asegura que todos los registros creados desde bots conversacionales (como Odoo Livechat, Scripts de CRM, o integraciones automáticas) se guarden como type = 'lead', incluso si el sistema por defecto los crearía como oportunidades (type = 'opportunity').

Características principales

  • Forzado automático de type = 'lead' en creación.
  • Compatible con modo Leads/Oportunidades activado.
  • Detección por:
    • utm.source (fuente que contenga la palabra "bot")
    • crm.tag (etiquetas que incluyan "bot")
    • channel_id (canal Livechat)
  • Instalación simple, sin configuración adicional.
  • Removible sin efectos colaterales: al desinstalar no quedan datos residuales.

Instalación

  1. Copiar el módulo en tu carpeta de addons.
  2. Actualizar la lista de módulos desde el backend o vía terminal.
  3. Instalar desde el menú de Aplicaciones como "CRM: Forzar Leads desde Bot".
